# pair-wise-yy-58 大型构件吊装三维校核平台

围绕大型转换桁架吊装方案，提供三维场景、时间轴校核、冲突定位、条件评论和多角色签署工作流。页面支持拖动旋转吊装场景、编辑步骤参数、处理规则冲突、恢复本地草稿并锁定发布版本。

## 技术栈

Vue 3、Quasar、Pinia、Vue Router、Apollo Client、GraphQL、Three.js、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

端口：`62058`

```bash
npm run build
```

数据草稿保存在浏览器 `localStorage`，Apollo 内存缓存保存吊装方案版本快照。

## 排程账（/schedule）

吊车、吊装步骤、回转占位接成一本排程账（`src/schedule/`）：

- **按时段 + 占位预占设备**：每个步骤在其 `[开始, 结束)` 时段为每台参与吊车生成一条占用，占位为以吊车站位为圆心的扇环（方位角区间 + 半径，支持跨 0°）。
- **重叠即列冲突**：同一吊车时段重叠报「同机时段冲突」；不同吊车时段重叠且两扇环几何相交（距离 < 半径和且对向方位角落入彼此扇区）报「回转占位相撞」。同一步骤内的双机协同不算冲突。
- **失败恢复**：风停或吊车故障登记后，受影响的待执行步骤标记失败，已完成步骤的占用（retained）不释放；条件解除后从最早失败步骤起重试，失败点之后的步骤按原顺序顺延重排，重排窗口会避开所有既成占用与不可用窗口。
- **旧步骤补迁**：旧台账步骤缺结束时间时，按原时长 `duration` 补齐后入账。
- **先到先得**：两名调度员提交同一时窗时，按入账序号先到者 `held` 占用，后到者 `queued` 并给出同长度备选时窗，确认备选后转为正式占用。

引擎为纯函数，可独立运行冒烟测试：

```bash
npm run test:engine
```
